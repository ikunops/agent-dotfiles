# 网盘分享页分层截图流水线（Pan Share Screenshots）

从"给 130 个课程素材补网盘截图"的真实战役中提炼。适用于夸克网盘为主、百度网盘为辅的分享页，
任何"点开分享链接 → 进入子目录 → 截真实内容 → 挂到商品图"的场景。

## 产出规范（与既有素材库一致）

- 尺寸：`clip={'x': 45, 'y': 60, 'width': 745, 'height': 875}`（避开页面边框与分享者信息条）
- 命名：`m{素材id}_share_C1/C2/C3.png`（C1=课程目录层，C2/C3=章节/文件层或滚动分段）
- 挂库：素材表 `images` 是 **JSON 列，直接存 Python list**——用 `json.dumps` 存字符串会变成
  双重编码，发布时图片逐字符遍历全部失败（真实事故：3 件商品图全挂）。修复：
  `JSON_TYPE(images)` 应为 `ARRAY`。
- 每张必须人工目检后再挂库（截图对不对、露不露名、是不是空壳）。

## 五步流水线

1. **目录树采集**：对库里每个分享链接跑一个"列目录"脚本（Playwright 无头），
   产出 `{分享名: {top: [顶级条目], subs: {文件夹: [子内容]}}}`。**必须点进一层**——
   很多库分享的根目录只有一个同名包装文件夹。
2. **严格匹配**：拿**子文件夹实名**对素材标题做匹配，宁可漏配不可错配。
   反例教训：按名字匹配到"MySQL架构设计课｜源码级优化+高可用方案"，结果该文件夹
   8 个章节全是 **0 项** 的空壳——空壳课程的名字可以很正规。匹配后必须抽查内容量
   （看"±N项"标记，163KB/11 个文件这种基本是空的）。
3. **点击链截图**：作业格式 `[{prefix, url, clicks: [包装层, 课程层, 章节层]}]`，
   每层进入后截图。点击成功的判定**必须用面包屑**（全部文件 / xxx），不要相信点击动作本身。
4. **平铺课程滚动补段**：有些课程目录不分章节、内容顺序平铺——不需要分级，直接在
   课程层滚动截 2~3 段（首屏 + 中段 + 后段），每段都是真实条目，照样是合格素材图。
5. **挂库 + 重发**：图片写到素材 images 列表（promo 图在前、share 图在后）；
   在售商品要换图 = 下架 → 重发（走系统 batch_publish，自动绑卡券+补库存）。

## DOM 坑速查表（每条都是真实踩过的）

| 症状 | 根因 | 解法 |
|---|---|---|
| 单击文件夹只勾选不进入 | 夸克新版列表单击=选中 | 单击后校验面包屑，未进入则 `el.dblclick()` 兜底 |
| 点击"成功"但页面没变 | antd/React 吞点击或节点重渲染 | 以**面包屑出现 `/`** 为成功判据；失败重试（换元素/双击） |
| 列表只截到前 10 条 | 虚拟滚动，DOM 不随文本增长 | 滚动用 `scrollTop`（找 scrollHeight>clientHeight 的容器）循环到底，判据是**高度不再增长** |
| 目标行永远找不到 | 行 top 与表头底线相等被 `>` 过滤 | 容差改为 `>= listTop - 4`；优先用 `page.get_by_text(name)` 的 locator 路径 |
| 候选点到导航/按钮 | 全页文本匹配命中"会员中心"等 | 只取"修改日期"表头之后、"转存"之前区段；且要求**下一行是 N项**（文件夹特征） |
| 截图里出现登录弹窗 | 分享页弹 QR 码 | Escape + JS 移除 `modal/dialog/mask/overlay/login` 且宽>300高>200 的节点 |
| 批量跑全部 notfound | 单步调试好的逻辑批量失效 | 先查**作业数据本身**（上次事故：jobs 文件少了 clicks 字段，15 个全秒败）；再查容器内脚本版本 md5 |
| 同一脚本单跑好、批量坏 | 时序/限流 | 每作业间 sleep；加载校验重试（"网络不见了"页面要整页重开） |

## 合规红线（2026-10-01 K12 商品被判违规下架的复盘）

- 截图只用**通用名层级**：年份/科目/章节文件夹（"2027年高一""语文课程""第02章 xxx"）。
- **绝不出现**：真实老师名（"01.2027年高一语文国家玮"这类）、分享者头像与实名条
  （裁剪 top≥100 可去掉）、网盘账号名。
- 露名字的层级宁可不用；主图也不建议与截图拼在一张里（主图归主图、实拍归实拍）。

## 部署形态

本流水线在 闲鱼系统服务器（192.168.94.20）的 backend-web 容器内运行
（容器里有 Playwright + chromium + 中文字体，产出目录 `/app/static/course-images` 即素材图片根）。
脚本模式：宿主机写好 → `docker cp` 进容器 → `nohup python xxx.py` 后台跑 → 轮询结果 JSON。
换新项目时按上述模式重写三件套：`list_tree`（采目录树）、`course_shots`（点击链截图）、
`scroll_shots`（平铺滚动段），坑表照抄即可。
