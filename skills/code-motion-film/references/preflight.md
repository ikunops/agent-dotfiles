# 交付前对账表

提交任何代码动画前，逐行核对。每条给「症状 → 自查问题 → 修法」。

---

## A. 可辨识性

| 症状 | 自查 | 修法 |
|---|---|---|
| 认不出画的是什么 | 静音测试：给不知情的人看，能说出这是什么吗 | 重画轮廓，指向原型；加特征部件 |
| 暗成一团黑影 | 暗部还有可辨轮廓/边缘光吗 | 提亮轮廓、加边缘光、缩小暗区 |
| 太抽象像随机形状 | 形状指向原型吗 | 用可识别的简化（俯视人=圆+肩线） |

## B. 投影自洽（同帧同一台相机）

| 症状 | 自查 | 修法 |
|---|---|---|
| "精神分裂"感 | 同层元素是否都同一投影 | 统一投影；或明确分成世界层/HUD 层 |
| 同一层里两种投影硬拼 | 每个元素单独看是哪个投影 | 统一投影；确需混用就分成两个空间层 |
| 一个物体内部投影打架 | 同一物体内部的部件是同一投影吗 | 统一为同一视角；不只是跨物体，**单个物体内部也不能混** |
| 说平面不能运镜 | 是整层 transform，还是每帧重算轮廓 | 平面也能环绕、升降、推拉；只要形状随相机重算 |
| 轮廓不变，只是整图在转 | 抽三帧看同一物体的形 | 改成逐帧投影；否则只是纸片翻转 |
| 运镜时字跟着变形/缩放 | 文字层是否独立于相机 | 字幕固定屏幕层，不参与投影 |

## C. 运动为增量

| 症状 | 自查 | 修法 |
|---|---|---|
| "滑动现形" | 是 clip/wipe/淡入 冒充生长吗 | 改成描线/逐个落下/弹性登场 |
| 抽中间帧看不出进度 | 中间帧能看出"长到哪"吗 | 让进度可量化（笔尖位置、构件数量） |
| 命令行整段蹦出 | 是逐字符吗 | `slice(0, floor(p*len))` + 光标 |
| 光标不闪 | 有闪烁吗、敲完消失吗 | `sin(frame*0.3)`，完成后隐藏 |

## D. 并发生长的接口

| 症状 | 根因 | 自查 | 修法 |
|---|---|---|---|
| 几段生长互相穿过 | 各段无起点/终点约定 | 每条生长的起点依附什么、终点接哪里 | 交接点抽成共享常量；未接处留白 |
| 同时长但节奏参差 | 各段各起计时器 | 是否共享同一弧长速度/构件节拍 | 用同一把尺子，相位差写成显式常量 |
| 接棒处停顿或跳线 | 两段各自写了"差不多"的端点 | 前段末点与后段首点坐标差 | 双方引用同一常量；坐标差必须为 0 |
| 看不出谁接谁 | 前沿不可辨 | 每条生长的前沿能否定位 | 给前沿可见标记；交叉处断开 |
| 改了一个节奏点，要改好几处 | 时间源分裂 | 有多少个独立的时间变量 | 合并成单一世界状态，派生量统一算 |
| 字幕/构件比画面早或晚 | 事件绑在帧号 | 触发条件是不是谓词 | 改成"某物已到位"的谓词 |
| 某一拍怎么调都读不出 | 构图冲突被当成数值问题 | 是否已试过位移/缩放/层级仍不行 | 重排走位、时序、视角，不调参数 |
| 连续改 3 次仍不通 | missing 设计层判断 | 这一拍观众必须读到什么 | 停下调参，重设计这一拍 |
| 成片与确认版不一致 | 把确认当风格偏好 | 是否与确认版做过同机位对照 | 反推成具名常量，只做增量 |

## E. 文字

| 症状 | 自查 | 修法 |
|---|---|---|
| 有"旁白/开始/先要有路" | 是导演口令吗 | 删，只留内容 |
| 有未要求的品牌标签 | 用户要过吗 | 删 |
| 字压人脸/身体 | 逐帧看重叠 | 标签改固定预留位，或加偏移 |
| 两个标签叠一起 | 逐帧看 | 错开位置/时间 |
| 字幕跟镜头缩放 | 文字层是否屏幕固定 | 文字写在运镜层之外 |
| 静止帧不撞、但动的元素扫过来 | **轨迹检查**：逐帧扫整条时间线了吗 | 跑 `scripts/trajectory.cjs`，看是否有「帧区间」告警 |
| 标签被运动的车/滑块/光标压到 | 运动元素的**扫掠包络**算过吗 | 算出包络（所有帧矩形的并集），标签放到包络外或设计离场时机 |
| 细线擦过文字一角没被发现 | 7×4 采样网格有盲区 | 矩形相交这一路也要看，不能只看像素命中 |

## F. 物理

| 症状 | 自查 | 修法 |
|---|---|---|
| 物体脱离路径横飞 | 位置和朝向都取自同一条路径吗 | 从曲线取点，用切线定朝向 |
| 轨道交织成一团 | 分叉是平滑并入吗 | 用同心圆弧/S 形切线 |
| 弯道上构件挤成一团 | 构件是按「弧长等距」排的吗 | 按累积弧长重采样，不要按索引等步长（直线没问题，弯道会挤） |
| 看不出转身 | 有镜像+挤压+朝向提示吗 | 三件套一起上 |
| 匀速飘 | 有重力/惯性吗 | 落下加速，抛出走弧线 |

## G. 滤镜与颜色极性

**根因：用 CSS `filter: invert()` 做风格时，语义会反转。**
你写的深色常量会渲染成**浅色**；你写的浅色常量会渲染成**深色**。
于是你以为在画「浅面 + 深线」，实际得到「深面 + 浅线」——主体看起来像另一种东西。

| 症状 | 自查 | 修法 |
|---|---|---|
| 主体看起来像另一种东西 | 浅色面上是深色线，还是反过来 | 用渲染后的真实像素取样反推（下方脚本） |
| 背景与主体的明暗关系反了 | 同上 | 同上 |
| 改了颜色但没变化 | 你改的是源色还是渲染色 | 先测再改 |

**实例**：某支片用 `invert(0.93) hue-rotate(188deg)`，设计师以为在画"浅色面 + 深色轮廓"，
实际渲染出来是"深色面 + 浅色轮廓"——比例完全颠倒，物体看起来像另一类东西。

**快速反推脚本**（对任意已渲染帧，取样三到五个关键点）：
```python
from PIL import Image
im = Image.open("out/frame.png").convert("RGB")
# 坐标换成你要核对的关键点：主体亮面、主体暗面、背景
for lbl,(x,y) in {"主体亮面":(880,300), "主体暗面":(600,600), "背景":(1700,900)}.items():
    print(lbl, im.getpixel((x,y)))
```
然后对照你源码里这一点写的是哪个常量，即可得出映射关系。

**建议**：一旦用了 `invert`，在文件头部写一行注释记下极性（如 `// invert 后：深色常量变亮，浅色常量变暗`）。

## H. 风格分家

| 症状 | 自查 | 修法 |
|---|---|---|
| 四支看起来一样 | 画法/投影/色彩/材质四项，任意两支有三项相同吗 | 至少换画法（线型/体积/材质） |
| 只换了颜色 | 是不是只调了 hue/filter | 换真正的画法，滤镜不算分家 |

## I. 自检与渲染

| 症状 | 自查 | 修法 |
|---|---|---|
| 漏掉中间错误 | 抽了多少帧？覆盖动作中段/转场/文字瞬间了吗 | 每 15–20 帧抽一帧，拼成 sheet 扫 |
| 渲染出旧画面 | 清缓存了吗 | `--bundle-cache=false` |
| 说"检查过了"但没抽够 | 能说出抽帧区间吗 | 先说明抽帧密度再下结论 |

## J. 生成方式与转场

| 症状 | 自查 | 修法 |
|---|---|---|
| 场景切换像"没加载完" | 是不是拿贴片/描线这类生成手法当转场 | 转场从推拉、形变、材质、剪辑四组里选 |
| 物体像幽灵浮现 | 是不是用淡入代替生成 | 按主体选描线/逐个落下/弹性登场/结构搭建/贴片/水墨 |
| 年画式贴片像盖板 | 每块是不是独立进度、贴边可见 | 分块推进，保留贴边压痕 |
| 水墨像光圈 | 是不是放大了圆形遮罩 | 用噪声阈值推进 + 湿边 + 速度衰减 |
| 转场没有理由 | 能说清为什么现在换吗 | 加动机，或改成硬切 |
| 全片转场方向混乱 | 同方向的转场语义一致吗 | 统一方向含义 |
| 一条推镜头硬拼几个场景 | 空间连续吗、主体连续吗、路径规划过吗 | 要么真做一镜到底，要么用形变/剪辑 |
| 文字跟着转场翻转或缩放 | 文字层是否独立 | 字幕固定在屏幕层 |
| 场景切换像 PPT 翻页 | 交接帧有没有连续证据（主体/形状/运动/空间/方向） | 改成同形接力、单体环绕或生成物接力；没有证据的硬切写明动机 |
| 黑屏/闪白后才出现新场景 | 是不是把黑场当默认转场 | 只在时间跳跃/章节分隔使用；业务切场优先保持画面连续 |
| 同形物件交接时“只是都像” | 中心、大小、转向、速度连续吗 | 让两个物件在交接帧对齐同一位置与同一运动状态 |
| 车/产品换面靠黑场 | 能不能围着同一主体环绕到新机位 | 用同一主体、同一世界坐标连续运镜，逐帧重算投影 |
| 线条/粒子新场景像淡入 | 旧场景残余物有没有成为新场景的结构起点 | 从端点继续生长或从粒子重新聚拢，不能只叠一层 |

## K. 规格与参考

| 症状 | 自查 | 修法 |
|---|---|---|
| "这不是那个东西" | 体裁查清了吗，还是按名称字面猜的 | 查实际形态，重写一句话规格 |
| 越改越不像 | 改的是规格层还是参数层 | 规格层问题就重启，别在错的基础上打磨 |
| 复刻了却不像原片 | 只量了一帧，还是量了运动逻辑 | 补测单镜时长、亮度分布、信息密度 |
| 平面被做成伪 3D | 是否给整层加 transform 冒充运镜 | 改成每帧重算轮廓，平面也能真运镜 |
| 放大后发虚 | 渲染尺寸按最终观看尺寸留余量了吗 | 提高分辨率，保持边缘锐利 |

## L. 节奏与可读性

| 症状 | 自查 | 修法 |
|---|---|---|
| 像幻灯片 | 单位时间内有没有可见的持续变化 | 加增量动作，别只做整块出入 |
| 像快进 | 提速是不是全局乘了一个系数 | 只压等待，不压阅读与动作完成 |
| 字刚出来就被切走 | 每屏停留 >= 可读下限吗 | 按字数算停留时长，重排时间线；跑 scripts/readability.cjs |
| 全片等速 | 有无快慢起伏 | 信息密处放慢，过渡处加速 |

## M. 层级与质感

| 症状 | 自查 | 修法 |
|---|---|---|
| 画面简陋 | 环境层/次要元素/前景/材质齐了吗 | 先补层级，别急着加特效 |
| 加光后更脏 | 缺的是结构信息还是光 | 补结构与环境，别压暗了事 |
| 同类元素乱叠 | 两两比过矩形吗 | 分层 + 最小间隙常量 |
| 道具不合场所 | 这个场所会出现这个东西吗 | 换道具或换场所 |

---

## 一句话总纲

**观众看不懂 = 失败。** 每样东西能认出、每个变化能读出、文字不添乱、物理不穿帮、风格真分家、自检够密。
