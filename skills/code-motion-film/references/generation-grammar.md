# 生成语法与转场语法：两个独立的轴

主文件第三节与第七节的展开。这一页解决最常见的混淆：**东西怎么出现** 和 **场景怎么接** 是两件事。

---

## 一、先分清

| 轴 | 回答的问题 | 作用范围 |
|---|---|---|
| 生成方式 | 一个东西怎么从无到有 | 元素内部 |
| 转场方式 | 一个场景怎么变成下一个场景 | 场景之间 |

混用会出现两类怪东西：

- 用生成手法当转场：场景切换时整块贴片盖过来，观众以为是没加载完。
- 用转场手法当生成：物体靠淡入出现，看起来像幽灵浮现。

**唯一合法的跨界是粒子**：聚拢是生成，消散是转场。

---

## 二、生成方式

### 1. 描线生长 line-draw

线沿路径一帧帧延长。适合骨架、路径、边界、连接关系。
实现：按弧长或 stroke-dashoffset 推进；前沿要有可辨的线头。

### 2. 逐个落下 stagger

重复构件按顺序一个个落位，落位时自身也从 30% 长到 100%。
适合枕木、砖、台阶、栏杆、座位、音符。

### 3. 弹性登场 pop-in

单体从 0 缩放到位，带轻微过冲。缩放锚点在**生长基座**（脚、底边、铰链），不是几何中心。
适合人、道具、按钮、标注点。

### 4. 结构搭建 build-up

像数月延时摄影：地基 → 骨架 → 楼板 → 墙体 → 装饰。每层有自己的开始与时长；
脚手架可以在完成后拆除，**拆除本身也是动画**。适合建筑、装置、机械、系统。

### 5. 拆改重组 rebuild

先长成形态 A，再拆掉一部分，用拆下的料拼成形态 B。拆除是逆生长，不是淡出。
适合表达演化、迭代、改造。这是生长的高级形态。

### 6. 贴片生长 paste-on（年画式）

画面预先分块，按顺序一块块贴上去，贴到哪哪显形。
适合成块色面、贴纸感画面、强调一层层搭起来的空间关系。
关键：每块独立进度、可见的贴边、符合阅读或构造顺序。

**与描线的区别**：描线是线在推进，贴片是面在推进。描线适合骨架与路径，贴片适合成块的色面与预设贴图。

### 7. 水墨侵染 ink-bleed

墨点落下，沿纸纤维向外扩散，边缘有机、速度衰减。
适合东方质感、记忆与情绪段落、从抽象到具象。

实现要点：
- 用噪声场（fbm / value noise）做阈值推进，而不是放大一个圆形遮罩。
- 湿边：外缘颜色更深，内部更淡。
- 扩散速度随时间衰减（开局快、后段慢）。
- 可以多点落墨，但要有主次：一个主墨点带节奏。
- 纸纹参与计算，否则会像贴了一层渐变。

### 8. 逐字符输出 type-on

文本按字符推进，带光标。命令行、代码、输入框必须逐字符，不能整段蹦出。
执行结果按真实终端逐行刷出，不是一次性打印。

### 附：粒子聚拢 gather

粒子从外部汇聚成形。适合从抽象到具体、从散到聚。

## 三、转场方式

### A. 运镜类（镜头动到下一场景）

| 手法 | 用途 | 注意 |
|---|---|---|
| 推 push in | 强调、进入细节、进入内心 | 推到极限要由新场景接住 |
| 拉 pull out | 揭示环境、收束情绪 | 拉出后要有新信息 |
| 平移 / 摇 pan | 并列、沿线展开 | 方向要一致，反复左右摇会晕 |
| 升降 pedestal | 层级、从地到天 | 每帧重算地平线位置、上下间距、遮挡范围；整层 translate 是假的 |
| 环绕 orbit | 立体感、仪式感 | 每帧重算轮廓与遮挡，正圆变椭圆、侧面转出来；整层 rotate 会像纸片翻转 |
| 变焦 zoom | 压缩空间 | 不改变透视；滥用像廉价特效 |
| 甩镜 whip pan | 节奏切换、时间跳跃 | 配运动模糊，落点要清楚 |

### B. 形变类（物体变成另一个物体）

| 手法 | 用途 | 注意 |
|---|---|---|
| 形态延续 morph | 一镜到底首选 | 前后两个形要有共同骨架 |
| 镜像 mirror | 立场/时间反转 | 翻转轴要有语义；文字不能跟着翻 |
| 遮罩 wipe | 场景切换 | 遮罩形状要来自画面内已有元素 |
| 同构替换 match cut | 最省力也最高级 | 要求构图精确对齐 |

### C. 材质类（用画面材质完成切换）

- 粒子消散：消失、解体、时间流逝。
- 水墨 / 墨滴：东方质感、情绪段落。
- 光变（闪白 / 闪黑 / 光斑扫过）：强节奏、段落分隔。闪白过多会廉价。
- 烟 / 雾 / 水 / 沙：环境变化、时间流逝。
- 撕裂 / 翻页：只在内容本身是纸媒时用。

### D. 剪辑类（不靠运动，靠时间）

- 硬切：信息密度高时的正确选择，不是低级。
- 叠化：时间流逝、情绪软化、段落收束，0.8–1.5 秒。
- 跳切：同一主体不同时间，压缩过程。
- 闪白 / 闪黑：强拍强调，单次不超过 3 帧。

## 四、一镜到底不是一种转场

一镜到底是一整套约束：

1. **空间连续**：镜头路径在几何上说得通，不能瞬移。
2. **主体连续**：观者注意力有一个可跟随的对象。
3. **路径预先规划**：起点、途经、终点，以及在哪一帧完成"场景已换"的交接。
4. **元素复用**：上一场景的某个元素成为下一场景的构图骨架。
5. **持续微动**：有呼吸感，但不乱晃。

把几个独立场景拼起来、中间加个推镜头，不叫一镜到底。

## 五、转场选择表

| 情况 | 首选 | 避免 |
|---|---|---|
| 空间连续、强调不中断 | 形态延续、运镜、一镜到底 | 硬切 |
| 时间跳跃、压缩过程 | 跳切、叠化、甩镜 | 慢推 |
| 情绪转折、段落收束 | 叠化、光变、粒子 | 硬切 |
| 强节奏、卡拍 | 硬切、闪白、甩镜 | 长叠化 |
| 东方质感、记忆段落 | 水墨、粒子 | 几何遮罩 |
| 两个场景有同形物体 | 同构替换 | 加特效掩盖 |
| 平面风格 | 全部运镜都可用，只要形状逐帧重算 | 整层 transform 冒充运镜 |

## 六、通用规则

- **必须有动机**：转场要回答"为什么现在换"。
- **方向要有语义**：同方向的转场表达同一种关系，全片一致。
- **时长要短**：转场是标点不是句子，多数 0.3–0.8 秒。
- **文字层独立**：转场作用于画面层；字幕固定在屏幕层，不跟着翻转、缩放、消散。
- **卡拍**：有音乐时，转场完成点落在重音或小节线。
- **投影一致**：镜头可以环绕、升降、推拉；要求是同一帧所有元素由同一组相机参数算出，且元素形状随相机重算，不是整层做 transform。平面是画法，不是相机锁。

---

## 七、两轴组合的自检

每支片写一句话：**"用【生成方式】显形，用【转场方式】换场。"**

例：

- 讲解片：用描线 + 逐个落下显形，用硬切 + 平移换场。
- 故事片：用弹性登场 + 形态延续显形，用环绕 + 镜像换场。
- 知识栏目：用逐字落下 + 贴片显形，用叠化 + 光变换场。

如果这句话里同一格填了两个以上互斥的手法，说明还没定。
