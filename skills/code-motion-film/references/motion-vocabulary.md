# 运动语法详解

主文件第三节的展开。每种语法给出「是什么 / 何时用 / 实现要点 / 常见错误」。

---

## 1. 描线生长 (line-draw)

**是什么**：线条沿路径从起点一帧帧描到终点。

**何时用**：轨道、道路、数轴、边界、连线、签名、流程箭头。

**实现要点**：
- 用 `stroke-dasharray = L` + `stroke-dashoffset = L * (1 - p)` 实现，`L` 是路径总长。
- 折线要算总长，按 progress 取「已描出的那一段」（polyline tip）。
- 可加发光「笔尖」：一个圆点落在当前终点，画完即消失。
- 缓动用 easeInOutCubic 最自然；长线可分段。

**常见错误**：
- 用 clip/wipe 冒充描线 → 看起来像板子滑过，不是线在长。
- 笔尖没消失 → 线画完了还有个点在终点杵着。

---

## 2. 逐个落下 (stagger)

**是什么**：重复构件按顺序一个个出现。

**何时用**：枕木、砖块、楼梯、网格、栏杆、树、座位、音符。

**实现要点**：
- `stagger(frame, idx, start, gap, dur)`：第 idx 个在 `start + idx*gap` 之后开始，`dur` 内完成。
- 出现时自身也从 30% 长到 100%（宽度/高度），比单纯淡入更有"落下"感。
- `gap` 决定节奏：密集构件用 2–6 帧，稀疏构件用 15–30 帧。

**常见错误**：
- 全部同时出现 → 失去"逐个"感。
- 出现时只改透明度 → 像幽灵浮现，不像落下。

---

## 3. 弹性登场 (pop-in)

**是什么**：单体元素从 0 缩放弹到位。

**何时用**：人、道具、按钮、图标、卡片、标注点。

**实现要点**：
- back 缓动：`1 + 2.2*(t-1)^3 + 1.2*(t-1)^2`，末尾轻微过冲再回落。
- 缩放锚点要设在元素的「生长基座」（如人的脚、按钮的角），不是几何中心。
- 可叠加轻微位移（从上落下/从侧滑入）。

**常见错误**：
- 从几何中心缩放 → 像气球吹大，不像长出来。
- 过冲太大 → 像果冻，不稳重。

---

## 4. 结构搭建 (build-up) —— 工地监控式生长

**是什么**：像几个月延时摄影那样，结构从地基开始一层层长出来，可拆可改。

**何时用**：建筑、装置、复杂机械、系统架构、任何"从零建成"的叙事。

**实现要点**：
- **分层生长**：先地基 → 骨架/柱 → 楼板 → 墙体 → 装饰。每层有自己的 start/dur。
- **相机跟随**：镜头随结构升高而上摇/拉远，让观众感到"在长高"。
- **脚手架感**：结构完成前可保留辅助线/脚手架，完成后拆除——拆除本身也是动画。
- **拆改重组**：先长出 A → 拆掉某部分（元素逆生长/粒子消散）→ 用拆下的料拼成 B。这是表达"演化"的核心手法。
- **时间流逝暗示**：可加天光变化（清晨→黄昏→夜）、云影移动、季节色变。

**常见错误**：
- 一次全出来 → 失去"建造过程"的叙事价值。
- 没有分层 → 像整体淡入。
- 拆改时用硬切 → 应让拆除也是可见的逆过程。

---

## 4b. 贴片生长 (paste-on) —— 年画式

**是什么**：画面预先分成若干块（背景、中景、主体、装饰），按顺序一块块贴上去。贴到哪，哪就显形。

**与描线的区别**：描线是线在推进，贴片是面在推进。

**实现要点**：
- 每块有自己的顺序与进度，不要全屏共用一个进度。
- 贴的边界要能看见：一条细的压痕/投影/白边，跟着前沿走。
- 顺序符合阅读或构造顺序（先远后近、先底后上、先大后小）。
- 块之间允许 1-2 帧重叠，避免缝隙。

**常见错误**：整屏 clip 冒充贴片；块太大看不出过程；顺序随机。

---

## 4c. 水墨侵染 (ink-bleed)

**是什么**：墨点落下，沿纸纤维向外扩散，边缘有机，逐步染出内容。

**实现要点**：
- 噪声阈值推进，不是放大圆形遮罩。
- 湿边：外缘深、内部浅。
- 扩散速度随时间衰减。
- 纸纹参与计算。

**常见错误**：圆形 mask 放大（那是光圈）；边缘过滑；匀速扩散。

---

## 5. 逐字符输出 (type-on)

**是什么**：文本一个个字符出现，带光标。

**何时用**：命令行、代码、终端、输入框、搜索框、聊天消息。

**实现要点**：
- **严格按字符数**推进：`text.slice(0, floor(p * text.length))`。中文按字、英文按字符。
- **光标闪烁**：一个方块/竖线，`Math.sin(frame * 0.3) > 0` 控制显隐。
- **打字节奏不均**：可给每个字符加微小的随机延迟，更像真人（可选）。
- **换行时机**：到行宽才换行，不要预设。
- **命令执行**：敲完回车后，输出可以是"逐行刷出"或"一次性出现"（终端真实行为是逐行）。
- 多行输入框：上一行敲完才出现下一行。

**常见错误**：
- 整段瞬间出现 → 就是"复制粘贴"，没有打字感。
- 光标不闪或不消失 → 敲完还杵着。
- 中英文混排按字节数算 → 中文字数算错。

---

## 6. 粒子消散 / 聚拢 (dissolve)

**是什么**：物体沿轮廓采样发射粒子，淡出飘散；反向即聚拢成形。

**何时用**：转场、消失、抽象化、变身、强调。

**实现要点**：
- 沿物体**轮廓取样**（不是矩形内随机），粒子才像从物体本身散开。
- 每个粒子有：初始位置、速度方向、大小、启动延迟 `d`。
- 速度方向沿法线向外 + 轻微上飘（`vy` 偏负）+ 二次项重力。
- 粒子随进度缩小、变淡：`r *= (1 - t*0.6)`，`opacity *= (1-t)^2`。
- 物体本体同步淡出（`1 - progress`）。

**常见错误**：
- 粒子在矩形里随机 → 像雪花，不像物体散开。
- 粒子不缩小 → 像撒了一把石头。
- 本体不淡出 → 粒子散了物体还在。

---

## 6b. 逐字落下 (drop-chars)

**是什么**：文本一个字一个字从上方落下归位（不是整行淡入）。

**何时用**：标题、落款、强调句。**可选手法，不是每处都用**——字幕正文不要用（拖慢阅读）。

**实现要点**：
- 逐字 progress，配 back 缓动，落下带轻微过冲。
- 每个字下落**幅度要小**（约 0.5–0.6 倍字号），否则会短暂越过并撞到下方元素（时间线、标签）。
- 字宽：CJK 按字号，拉丁/数字按约 0.56 倍字号估宽，才能正确排版居中。

**常见错误**：
- 下落幅度过大 → 中途压到别的文字（几何检查器会抓到）。
- 整行一起落 → 退化成普通淡入。

---

## 7. 转场衔接 (transition)

**转场分四组**：运镜（推拉摇移升降环绕变焦甩镜）、形变（形态延续/镜像/遮罩/同构替换）、材质（粒子/水墨/光变/烟水沙）、剪辑（硬切/叠化/跳切/闪白闪黑）。

选择规则、时长、方向语义、一镜到底的约束，见 `generation-grammar.md`。

一句话：转场是场景之间的事，不是元素内部的事。别把生成手法当转场用。

---

## 8. 运镜 (camera)

**是什么**：镜头运动。

**要点**：
- **平面画法不等于相机不动**。逐帧渲染时每一帧都是重画的一张图，相机参数变了，这一帧所有形状就跟着重算。平面风格照样能环绕、升降、推拉。
- 真的运镜 = **形状随相机重算**：环绕是正圆逐步变椭圆、侧面转出来、遮挡关系随角度变；升降是地平线位置和上下间距变；推是近处放大快、远处慢。
- 假的运镜 = **整层 transform**：`rotateY` 当环绕、`translateY` 当升降、等比 `scale` 当推拉。形不变只变位置，观众看到的是纸片在动。
- 低面数就够：8–16 段多边形柱体、几个盒子拼场景，轮廓一动就能读出体积，不需要真 3D 引擎和光照。
- **文字层必须屏幕固定**，不受运镜影响，否则会跟着缩放导致叠字/出框。
- 运镜要慢，一镜到底时整片保持微动（呼吸感），别静止也别乱晃。
- 只在故事需要时用，不是每段都加。

**判据**：抽三帧看同一个物体的**形状**有没有变。只有位置变、形状没变，就是假的。
