# 片种手册：类型决定结构

主文件〇节的展开。片种不是风格标签，它决定四件事：**时间轴由什么驱动、镜头单位是什么、文字承担什么、失败的典型样子**。选错片种，后面所有参数都在错的方向上优化。

---

## 一、先分清六类

| 片种 | 时间轴驱动 | 镜头单位 | 文字角色 | 典型失败 |
|---|---|---|---|---|
| 讲解片 / 科普 | 讲解逻辑（概念→机制→例证） | 一镜到底或少量镜头，镜头服务解释 | 字幕承担主要信息，图承担结构 | 画面在动但没在解释；单位时间信息量低 |
| 知识栏目短片 | 观点推进 + 情绪节奏 | 分镜，按论点切 | 文字是主体，画面是氛围 | 变 PPT；文案空；全片一个语速 |
| 故事片 / 叙事短片 | 事件因果 + 情绪曲线 | 分镜，运镜服务情绪 | 文字极少，靠画面叙事 | 用旁白解说画面；人物动作不合逻辑 |
| 教程 / 上手视频 | 操作顺序 | 固定机位或步骤特写 | 步骤编号 + 命令逐字符输出 | 整段代码蹦出；步骤跳跃；界面臆造 |
| 产品 / 宣传片 | 卖点排序 + 节奏高点 | 分镜 + 运镜，节奏快 | 短句、卖点、字幕条 | 只堆特效不讲价值；信息过载 |
| 音乐驱动 / MV | 音乐节拍与小节 | 卡点切换，或一镜到底内部卡点 | 歌词/关键词，随乐句出现 | 动作不卡拍；全片等速 |

---

## 二、每类的硬要求

### 讲解片 / 科普

- 每一拍必须回答一个具体问题；画面变化要对应"解释的推进"，不是装饰。
- 抽象概念必须有可见的对应物（形态、颜色、运动），且这个对应关系在片内保持一致。
- 允许保留"计算过程"这类中间态（识别框、数值、标注、步骤），因为它们是解释的一部分；但要保证可读、不遮挡主体。
- 时长可以长，但单位时间的信息量不能低。宁可少讲一个点，不要用空镜凑时长。
- 镜头可以一直动，但运动要有解释功能：靠近是"看细节"，拉远是"看整体关系"。

### 知识栏目短片

- 观点先行：开头 3 秒内让观众知道这支片在说什么。
- 文字是主体，所以排版就是美术：字阶、行距、留白、出现方式都要设计。
- 每次只推进一个观点；观点之间要有转折或递进，不能并列堆砌。
- 无旁白时，文字必须自己承担节奏：出现、停留、消失都要有设计。
- 互动用内容发问，不用平台话术。

### 故事片 / 叙事短片

- 事件因果优先：观众要能回答"他为什么这么做"。
- 不写旁白解释画面。画面能说清的，不要用字说。
- 运镜和转场只在情绪需要时用；为炫技加的运镜会打断叙事。
- 人物动作要符合物理与场所；接触关系、朝向变化必须读得出来。
- 风格服务故事：不同故事用不同画法，不能一套模板换颜色。

### 教程 / 上手视频

- 步骤必须可复现：观众照着能做出来。
- 代码、命令、输入框逐字符输出，带光标；执行结果按真实终端逐行刷出。
- 每一步有明确的状态变化：点哪里、出现什么、结果是什么。
- 界面元素按真实产品布局画，不要臆造控件与层级。
- 参数讲解要成组：先给最小可用示例，再展开可选项。

### 产品 / 宣传片

- 先定一句价值主张，再定分镜；每个镜头回答"这解决了什么"。
- 全片至少一个明确的视觉高潮，且卡在音乐重音上。
- 字幕短、少、准；不要用长句解释。
- 特效服务信息，不服务炫技。

### 音乐驱动 / MV

- 先有音乐，再有分镜。节拍点决定切换点与动作完成点。
- 全片等速等于失败；要有强拍与弱拍的差异。
- 歌词/关键词的出现要与乐句对齐，不能压拍。
- 配乐优先用现成曲子；合成音色容易发怪。
- 卡点不等于每拍都切；只在重音与段落转折处切。

---

## 三、混用规则

- 允许混（如讲解片里插一段故事、故事片里插一段数据），但必须有一个**主片种**；混入部分不能改变主时间轴的驱动方式。
- 混用点要明确：观众要能感到"现在换了一种讲述方式"，而不是莫名其妙地变慢或变快。
- 两种片种的文字密度差异很大，切换时要重新排版，不能沿用上一段的字号与停留时长。

---

## 四、选片种的自检

1. 这支片的时间轴由什么驱动？（逻辑 / 观点 / 因果 / 操作 / 卖点 / 音乐）
2. 观众看完应该记住什么？（一个机制 / 一个观点 / 一个故事 / 一个操作 / 一个卖点 / 一段情绪）
3. 文字承担多少？去掉文字还能看懂吗？
4. 这类片最典型的失败是什么？我现在有没有踩？
5. 如果用户只给了一个栏目名或片种名，我查清它的实际形态了吗？

五个问题答不上来，不要开始写代码。
