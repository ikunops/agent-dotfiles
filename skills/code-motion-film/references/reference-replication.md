# 复刻与规格：把参考变成可核对的数

主文件〇节与第十一节的展开。适用于"照着这个做""复刻一下""这不像"这类任务。

---

## 1. 先判画法，再选工具

拿到参考，第一步不是测量，而是判断它属于哪一类画面。判错画法，后面所有参数都白调。

| 你看到的 | 真实画法 | 正确做法 | 错误做法 |
|---|---|---|---|
| 平滑色块、边缘极锐、无纹理 | 平面矢量 / 纯色块分层 | SVG / Canvas 直接画形 | 用 3D 渲染再压平 |
| 有透视、有体积、有阴影 | 3D 或手绘透视 | 建相机、算透视、打光 | 用 2D 多边形硬凑透视 |
| 有笔触、有颗粒、有纸纹 | 手绘或合成纹理 | 贴纹理 + 抖动 + 边缘不齐 | 用纯色矢量画完再加噪点 |
| 明暗高度集中、大量近黑 | 有明确主光 | 先定光位与亮区，再画物体 | 全场均匀打亮再压暗 |

**判断方法**：放大到 400% 看边缘。矢量边缘是干净的抗锯齿；3D 边缘有景深与糊化；手绘边缘有抖动、有重叠笔触。三条不一样，技术路线就不一样。

## 2. 必测的六个量

不要用"感觉像"。至少量这六项，写下数值再动手：

1. **画幅与遮幅**：成片是 16:9 全画幅，还是有黑边？上下黑边各多少像素？内容区实际比例是多少？
2. **主体占屏比**：主体最宽处占画面宽度百分之几？这决定了构图疏密，也决定字号。
3. **亮度分布**：整体均值、中位数、最亮区占比、最暗区占比。用于判断"是不是全场均匀打亮"这一典型错误。
4. **主色**：主要三到五个色值。注意提取的是**渲染后的像素**，不是设计稿里的色号。
5. **边缘锐度**：同一物体边缘在 1:1 与放大 4 倍下的清晰度。参考锐利而你发虚，说明分辨率或缩放策略有问题。
6. **单镜时长**：一个画面停留多久、一个动作多久完成。这是节奏的基线。

## 3. 信息密度对齐

"简陋"几乎总是密度问题，不是技法问题。对齐时逐项问：

- 背景里有没有环境层（地面、墙面、天空、远景）？
- 有没有次要元素（其他行人、其他物件、装饰）？
- 有没有前景层（遮挡、框景、近处模糊物）？
- 有没有材质区分（不同表面的反光、粗糙度、纹理）？
- 有没有状态变化（光在变、物在动、背景在呼吸）？

**做法**：列一张层级清单，参考有几层就补几层。少一层，观众就会觉得"空"。但补的是**结构**，不是特效。

---

## 4. 常见退化：越改越不像

| 症状 | 真实原因 | 处理 |
|---|---|---|
| 越"优化"越像 PPT | 用滑动/淡入替代了逐帧变化 | 回到增量生长语法 |
| 加了光反而更脏 | 缺的是层级，不是光 | 先补环境层与前后景 |
| 平面被做成了伪 3D | 是不是整层 rotate/scale 冒充运镜 | 改成逐帧重算轮廓与遮挡 |
| 主体对了但整体廉价 | 信息密度低于参考 | 补次要元素、材质、环境 |
| 复刻了截图却不像原片 | 只复刻了单帧，没复刻运动逻辑 | 先写清镜头怎么动、信息何时出现 |

---

## 5. 复刻的交付顺序

1. 一页规格：画法 / 视角 / 主色 / 字号 / 遮幅 / 单镜时长 / 信息密度。
2. 三张定帧：最容易翻车的三个时刻，先出静帧给用户看。
3. 一段 5–8 秒样片：验证运动与节奏，不验证全片。
4. 全片。

任何一步被否，回到第 1 步重写规格，不要在已否决的定帧上继续调参数。
