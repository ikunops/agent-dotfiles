# 转场连续性：让上一帧和下一帧处在同一口气里

转场像 PPT，通常不是因为“切得多”，而是因为画面断了：黑屏、闪白、整块淡入、静帧等待以后，新场景才凭空出现。观众读到的不是“场景变了”，而是“刚才那段结束了，现在重新开始”。

所以先判一件事：**交接点有没有连续证据？** 有，才叫转场；没有，只能叫切页。

---

## 一、五种连续证据

跨场景切换时，至少保留一项。证据越多越顺，但一项都没有就是失败。

| 证据 | 观众实际看到什么 | 典型用法 |
|---|---|---|
| 同一主体 | 同一辆车、同一个人、同一个物件始终在画面里，变的是机位和信息 | 产品片、人物叙事、科普解释 |
| 同一形状 | 车轮的圆接上风车的圆，再拉远揭示摩天轮；形状在交接帧完全对齐 | 比喻、联想、两个不同场景但同构 |
| 同一运动 | 旋转、下坠、粒子流、线条生长跨过交接点继续推进 | 图形动画、抽象概念、风格化叙事 |
| 同一空间 | 镜头穿过门、窗、天窗、隧道，从外部进入内部 | 一镜到底、室内外切换、产品透视 |
| 同一方向 | 甩镜、平移、推拉的方向不反转，新场景从运动前方出现 | 快节奏蒙太奇、知识短片 |

注意：**“都有圆”不等于同形接力**。真正连续的同形必须同时对齐：

- 中心位置连续
- 画面占比连续
- 旋转方向连续
- 角速度连续
- 交接前后的遮挡/明暗关系说得通

只满足“两个东西长得像”，观众仍会觉得跳。

---

## 二、固定判定顺序

每次设计转场，按这个顺序问，前面的能用就不许跳到后面。

1. **能不能不切？**
   优先同一镜头完成：推、拉、环绕、升降、穿过入口。能一镜完成就不切成两段。

2. **必须换场，有没有可接力的形、运动或方向？**
   有就做 match cut。让旧场景的形、运动或方向延续到新场景，而不是加一个特效盖住断点。

3. **没有接力物，能不能围着同一主体换机位？**
   单体产品、人物、建筑优先环绕、升高、俯冲、穿入。不要用黑场换一个面。

4. **以上都不成立，才允许硬切、叠化、闪白、黑场。**
   必须在分镜或验收记录里写明：为什么这里必须断开。

硬切不是低级手法。信息密度高、时间跳跃明确时，硬切是正确选择；错的是**没有动机的黑场换页**。

## 三、三类可复用模板

### 1. 同形接力（match cut）

**用途**：两个场景不同，但存在同构的形或运动。

**例子**：少年骑车 → 镜头推近旋转的车轮 → 车轮占满画面 → 同中心、同大小、同转向的风车接上 → 镜头拉远，观众发现场景已经变成山坡上的风车。

**实现硬要求**：

- 两个物件在交接帧的**中心、大小、转向、角速度**必须连续。
- 旧物件不能先淡出再让新物件淡入；应该在同一运动过程中完成替换。
- 拉远后必须出现足以解释“为什么接得上”的新信息，不能只是换了个背景。
- 若用遮罩或蒙版辅助，遮罩形状必须来自画面内已有元素，不能凭空出现。

**验收**：抽交接前 5 帧、交接帧、交接后 5 帧，量圆的中心与直径；变化应是连续曲线，不能出现一帧归零或跳位。

### 2. 单体环绕 / 穿入（orbit reveal）

**用途**：同一主体，通过真实机位变化展示不同面，再进入内部。

**例子**：汽车正面 → 镜头拉远并环绕到侧面 → 侧面讲完 → 天窗打开 → 镜头升高、俯冲从天窗进入车内 → 落到正视内饰。

**实现硬要求**：

- 全程同一主体、同一世界坐标、同一条相机时间线。
- 每个机位都要**逐帧重算投影**：正圆变椭圆、侧面转出来、遮挡关系随角度变化。
- 不能用整层 `rotateY`、`scale`、`translate` 冒充环绕或穿入。
- 从天窗进入时，入口必须提前可见并真的打开；不能让镜头穿过一块仍然关闭的玻璃。
- 车内外的光照、材质、空间尺度要能接上，不能切到另一个“看起来像”的模型。

**验收**：抽正面、侧面、顶部、入口、车内五组帧；同一部件在相邻机位的轮廓和位置应能通过相机参数解释。只看位置变了、形状没变，就是假运镜。

### 3. 生成物接力（growth / particle）

**用途**：用线条、粒子、水墨等生成语言跨场景。

**例子**：上一场景最后一笔线条停在画面里 → 线头继续生长，长出下一场景的骨架 → 填充、上色、形成完整场景。

或者：粒子先聚成旧场景的主体 → 散开 → 沿同一运动方向重新聚成新场景的主体。

**实现硬要求**：

- 旧场景的残余物必须成为新场景的**结构起点**，不能只是在新画面上叠一层淡入。
- 线条要有可辨的线头，并按弧长连续推进；粒子要有明确的聚拢中心与运动方向。
- 场景替换发生在运动过程中，不是“旧场景消失 → 停一下 → 新场景出现”。
- 粒子消散后重新聚拢时，前后两团粒子应共享至少一个连续量：中心、速度方向、颜色族或整体轮廓。

**验收**：抽生长前、生长中、交接、生长后四组帧；中间帧必须能看出“正在从哪里长到哪里”，不能只看到透明度变化。

## 四、反例：这些默认判失败

- 黑屏 → 亮起 → 新场景
- 闪白 → 新场景
- 整屏淡出 → 整屏淡入
- 两个静止构图之间直接切，没有任何形状/运动/方向接力
- 字幕还在，画面却已经换了一个空间
- 同形物件只是“都像”，中心、大小、转向、速度全不连续
- 车/产品换面靠黑场，而不是环绕或穿入
- 线条/粒子新场景像淡入，旧场景残余物没有参与新结构
- 为了卡音乐拍点，硬把空间连续性打断

黑屏、闪白只允许用于：**明确的时间跳跃、章节分隔、强节奏标点**。使用时必须写动机，并在项目的转场清单中登记为例外。

## 五、抽帧验收

转场不能只看“我觉得顺”。每个交接点至少抽三组：

1. 交接前 5 帧
2. 交接帧
3. 交接后 5 帧

逐帧回答：

- 哪一项连续证据在起作用？
- 它在交接帧的值是什么？（中心、尺寸、方向、速度、空间位置）
- 有没有一帧出现全黑/全白/透明度归零？
- 新场景是从运动里长出来的，还是等旧画面结束后才出现？
- 字幕有没有跟着画面翻转、缩放、消散？

自动化辅助：

```powershell
# 单对交接帧：检查黑场/白场与亮度、主色、粗结构连续性
node skills/code-motion-film/scripts/transition-continuity.cjs --left before.png --right after.png

# 帧目录：检查第 120 帧附近，默认前后各 5 帧
node skills/code-motion-film/scripts/transition-continuity.cjs --dir frames --at 120 --radius 5
```

脚本只做启发式闸门，不能替代人眼。它擅长抓“黑屏→亮起”和“静帧直接切”，不能判断语义上的同形是否真的对齐。`--dir` 模式的帧文件命名见脚本顶部：支持 `120.png`、`frame-00120.png`、`frame_00120.png`。

### 章节黑场例外

如果黑场确实是章节分隔，不要改脚本阈值，也不要用 `--force` 这类全局开关。应该在 manifest 的单个转场上显式登记：

```json
{
  "transitions": [
    {
      "left": "frames/0200.png",
      "right": "frames/0220.png",
      "allowBlack": true,
      "reason": "第二章开始，明确的时间跳跃"
    }
  ]
}
```

例外必须逐条登记，并在验收记录里保留 `reason`；没有原因的例外不放行。

例外只放宽“接近全黑/全白”这一项；交接帧仍必须至少保留亮度、主色、粗结构中的一项，否则不放行。`reason` 少于 4 个字符会直接判配置错误。

## 六、交付清单

- [ ] 每个转场都回答了“为什么现在换”
- [ ] 每个转场至少保留一项连续证据
- [ ] 同形接力的中心、大小、转向、速度连续
- [ ] 单体环绕/穿入使用同一主体、同一相机时间线，投影逐帧重算
- [ ] 线条/粒子的旧残余物成为新场景的结构起点
- [ ] 没有把黑屏/闪白/整屏淡入当默认换场
- [ ] 章节黑场逐条登记了 `allowBlack` / `allowWhite` 与 `reason`
- [ ] 字幕固定在屏幕层，不跟画面转场
- [ ] 已抽交接前后各 5 帧并记录连续证据
