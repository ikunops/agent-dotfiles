# 韩先超 K8S 课程 - 思维导图

> 支持导入 XMind/MindMaster/MindNode/XMind 等工具
> 导入方法：复制下方缩进内容，粘贴到思维导图工具的"粘贴/导入"功能

```
韩先超 K8S 课程
├── 1. Docker 基础
│   └── Docker 容器
│       ├── Docker 概念与架构（Go 语言，2013 年）
│       ├── 安装（CentOS 7.6，yum 配置）
│       ├── 镜像管理（pull / push / save / load / tag）
│       ├── Dockerfile 语法（FROM / RUN /CMD /COPY/ADD/ENV/EXPOSE）
│       ├── Dockerfile 最佳实践
│       ├── 数据持久化（Volume 挂载 -v）
│       ├── 网络模式（bridge/host/joined/none）
│       └── 资源限制（--cpus / --memory）
│
├── 2. K8s 核心资源 - Pod
│   ├── Pod 概念
│   │   ├── 最小调度单元
│   │   ├── 共享 IP 和 Volume
│   │   ├── 自主式 vs 控制器管理
│   │   └── Pod 资源清单 YAML
│   ├── Pod 生命周期
│   │   ├── Pending → Running → Succeeded/Failed
│   │   ├── 重启策略（Always/OnFailure/Never）
│   │   └── Init 容器（前置初始化）
│   ├── 健康探测
│   │   ├── livenessProbe（存活检查）
│   │   ├── readinessProbe（就绪检查）
│   │   ├── startupProbe（启动检查·慢启动）
│   │   ├── 探测方式（httpGet/tcpSocket/exec）
│   │   └── 参数（initialDelaySeconds/periodSeconds/failureThreshold）
│   └── 临时容器
│       ├── 调试用途
│       ├── 无端口/无探针/无资源限制
│       └── kubectl debug 命令
│
├── 3. kubectl 命令行
│   ├── 语法（command / type / name / flags）
│   ├── 常用命令
│   │   ├── apply（声明式创建）
│   │   ├── get / describe / delete
│   │   ├── logs / exec
│   │   ├── scale / rollout
│   │   └── api-versions / explain
│   └── 输出格式（-o wide / yaml / json / custom-columns）
│
├── 4. K8s 控制器
│   ├── ReplicaSet
│   │   ├── 期望副本数 + 标签选择器 + Pod 模板
│   │   └── 多退少补
│   ├── Deployment
│   │   ├── 管理 ReplicaSet
│   │   ├── 滚动更新（maxSurge/maxUnavailable）
│   │   ├── 版本回滚（revisionHistoryLimit）
│   │   └── 扩缩容
│   ├── StatefulSet
│   │   ├── 有状态服务
│   │   ├── 稳定网络标识（Pod 名固定）
│   │   ├── 有序启停（index 顺序）
│   │   ├── Headless Service + volumeClaimTemplates
│   │   └── 更新策略（RollingUpdate/OnDelete）
│   └── DaemonSet
│       ├── 每个 Node 一个 Pod
│       ├── 日志收集（fluentd）
│       ├── 监控（Node Exporter）
│       └── 存储（glusterd/ceph）
│
├── 5. K8s 网络
│   ├── Service（四层负载均衡）
│   │   ├── ClusterIP（集群内访问）
│   │   ├── NodePort（节点端口 30000-32767）
│   │   ├── LoadBalancer（云 LB）
│   │   ├── ExternalName（DNS CNAME）
│   │   ├── kube-proxy（iptables / ipvs）
│   │   └── CoreDNS 服务发现
│   ├── IPVS 模式优化
│   │   ├── Hash 表（高效）
│   │   └── 调度算法（rr/wrr/lc/wlc/sh/dh）
│   ├── CNI 网络插件
│   │   ├── Flannel（VXLAN/host-gw）
│   │   ├── Calico（BGP + NetworkPolicy）
│   │   └── Canal（Flannel + Calico）
│   ├── Ingress Controller（七层负载）
│   │   ├── Nginx Ingress
│   │   ├── 高可用（keepalive + 多副本）
│   │   └── HTTPS 证书管理
│   └── 灰度发布（Canary）
│       ├── Header-based
│       ├── Cookie-based
│       └── Weight-based（0-100%）
│
├── 6. K8s 存储
│   ├── 存储卷类型
│   │   ├── emptyDir（临时）
│   │   ├── hostPath（宿主机目录）
│   │   ├── NFS（网络文件系统）
│   │   ├── PV/PVC（持久卷/声明）
│   │   └── StorageClass（动态供应）
│   ├── PV 生命周期
│   │   ├── Provision → Bind → Use → Release → Reclaim
│   │   ├── 访问模式（RWO/ROX/RWX）
│   │   └── 回收策略（Retain/Delete/Recycle）
│   ├── ConfigMap
│   │   ├── 非机密配置 key-value
│   │   ├── Volume 挂载 / 环境变量注入
│   │   └── 限制 1MiB
│   ├── Secret
│   │   ├── 机密数据 Base64
│   │   ├── Opaque/TLS/docker-registry 类型
│   │   └── 注入方式同 ConfigMap
│   └── Ceph 分布式存储
│       ├── 块存储 RBD / 文件系统 CephFS / 对象存储
│       ├── 组件（Monitor/Manager/OSD/MDS）
│       └── CSI 驱动集成
│
├── 7. K8s 安全 - RBAC
│   ├── 认证（Authentication）
│   │   ├── Token / SSL 证书
│   │   ├── ServiceAccount
│   │   └── UserAccount
│   ├── 授权（Authorization）
│   │   ├── Role / ClusterRole
│   │   ├── RoleBinding / ClusterRoleBinding
│   │   └── 动词（get/list/watch/create/update/delete）
│   └── 准入控制（Admission Control）
│       ├── MutatingAdmissionWebhook（变更）
│       ├── ValidatingAdmissionWebhook（验证）
│       └── 默认准入控制器
│
├── 8. 集群安装与部署
│   ├── kubeadm 安装
│   │   ├── 单 master 集群（学习环境）
│   │   ├── 多 master HA（生产环境）
│   │   ├── Containerd 运行时（v1.23/1.24）
│   │   ├── etcd 高可用
│   │   └── kubeadm vs 二进制对比
│   ├── 二进制安装
│   │   ├── 手动编译/下载组件
│   │   ├── 3 节点 etcd 集群
│   │   ├── TLS 证书（cfssl）
│   │   ├── Keepalived + Nginx LB
│   │   └── 组件健康检查
│   ├── Rancher 管理平台
│   │   ├── 多集群管理（混合云）
│   │   ├── 图形化界面
│   │   └── 企业级案例
│   └── K3s 边缘计算
│       ├── 轻量级 K8s
│       ├── 单二进制 + SQLite3
│       ├── 内置（containerd/Flannel/CoreDNS/Traefik）
│       └── 最低 512MB 内存
│
├── 9. 包管理与伸缩
│   ├── Helm v3
│   │   ├── Chart 包管理
│   │   ├── values.yaml 参数化
│   │   ├── Release 管理（install/upgrade/rollback）
│   │   ├── Repository 仓库
│   │   └── Tiller 已移除（v3 改进）
│   └── HPA/VPA 自动扩缩容
│       ├── HPA（水平扩缩·Pod 数量）
│       ├── VPA（垂直调整·CPU 内存）
│       ├── KPA（Knative·请求驱动）
│       ├── 指标（CPU/Memory/自定义）
│       └── 算法（30s 检测 / 5min 稳定窗口）
│
├── 10. 高级主题
│   ├── CRD 自定义资源
│   │   ├── API 扩展（自定义 RESTful API）
│   │   ├── OpenAPI v3 Schema 验证
│   │   ├── Namespaced / Cluster 作用域
│   │   └── Operator 模式基础
│   └── SpringCloud 电商项目
│       ├── 微服务容器化
│       ├── 服务注册发现（Eureka/Nacos）
│       ├── API 网关（SpringCloud Gateway）
│       ├── 配置中心
│       └── 数据库与缓存（MySQL/Redis）
│
├── 11. 监控、日志与追踪
│   ├── Prometheus + Grafana
│   │   ├── Prometheus 架构（Server/Exporters/Pushgateway/Alertmanager）
│   │   ├── PromQL 查询语言
│   │   ├── 多维数据模型（metric + labels）
│   │   ├── 服务发现（Target 管理）
│   │   ├── Grafana 仪表盘
│   │   ├── Alertmanager 告警（邮件/微信/钉钉）
│   │   └── Exporters（Node Exporter / kube-state-metrics）
│   ├── EFK 日志平台
│   │   ├── Elasticsearch（存储 + 索引）
│   │   ├── Fluentd（采集器·DaemonSet）
│   │   ├── Kibana（可视化 + 搜索）
│   │   └── 日志级别（DEBUG/INFO/WARNING/ERROR）
│   └── 全链路追踪
│       ├── Zipkin（Twitter 开源）
│       ├── Skywalking（Apache APM）
│       ├── Pinpoint（字节码注入）
│       ├── Trace + Span 概念
│       └── 服务拓扑分析
│
├── 12. DevOps 与 CI/CD
│   ├── Jenkins + K8s + Git + Harbor
│   │   ├── DevOps 理念（敏捷/CI/CD）
│   │   ├── Jenkins Pipeline（自动化构建/测试/部署）
│   │   ├── Git 版本控制 + Webhook
│   │   ├── Harbor 镜像仓库
│   │   └── 企业级 Devops 实践
│   └── Tekton K8s 原生 CI/CD
│       ├── CRD 定义（Task/TaskRun/Pipeline/PipelineRun）
│       ├── Google 开源
│       ├── 触发器（Event Listener）
│       └── 对比 Jenkins
│
└── 13. 服务网格 - Istio
    ├── Istio 四大功能
    │   ├── 连接（Connect）
    │   ├── 安全（Secure - mTLS）
    │   ├── 控制（Control）
    │   └── 观察（Observe）
    ├── Envoy Sidecar 代理
    ├── 流量管理
    │   ├── Gateway（入口网关）
    │   ├── VirtualService（路由规则）
    │   └── DestinationRule（负载均衡策略）
    ├── 灰度发布
    │   ├── 金丝雀发布
    │   ├── A/B 测试
    │   └── 蓝绿部署
    └── 可观测性
        ├── 指标（请求数/延迟/错误率）
        ├── 日志
        └── 链路追踪
```
