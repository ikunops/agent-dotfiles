# Swiss Editorial

瑞士国际主义风格：严格网格、极端字号对比、极小色域、单点信号色。内容像一篇排好版的文章，而不是一个"网页"。

## 风格特征

| 维度 | 取值 |
|---|---|
| 纸面 | `#FFFFFF` |
| 反色栏 | `#0C0C0D`（纯正黑，用于左栏） |
| 正文 | `#0C0C0D` / 次级 `#6B6B6B` / 深底上的次级 `#A7A7A7` |
| 线条 | `#E3E3E0` |
| 信号色 | `#FF4D00`（**全站唯一彩色**，用得极省） |
| 网格 | 左右分栏 `1.05fr .95fr`，左栏整块反色 |
| 字体 | Inter；全大写小标签 + `.16em` 字距 |
| 圆角 | **0** |

## 关键决策与理由

- **信号橙只出现在三处**：标题里的一个词（`<em>`）、按钮 hover、focus ring。第四处就是过度设计。
- **网格底纹不是装饰**：左栏那层 64px 网格（`opacity:.14` + 左上渐隐 `mask`）是"这是被设计过的文档"的声明。它必须极淡，且**只出现在深色栏**。
- **下划线式输入**：编辑排版的语言是文字与规则线，不是盒子。表单用 `border-bottom`，不用 `border` 全框。
- **方角是立场**：圆角会立刻软化掉这份冷峻。保持 0。

## 自带响应式（重要）

这个风格**自带 `@media (max-width: 900px)` 断点**：整块变成单栏，左栏（深色编辑栏）**隐藏**，只留表单。

这是有意的：编辑栏的内容是"氛围与主张"，移动端屏幕上它只会挤占空间。隐藏比堆叠更好。

```css
@media (max-width: 900px) {
  body { grid-template-columns: 1fr; }
  .panel { display: none; }        /* 深色栏整体隐藏 */
  .form-wrap { padding: 44px 24px; }
}
```

所以这个风格**不需要额外的 PC 适配**——它天生就是分栏的，桌面端直接可用。

## 微调旋钮

- 左侧栏想更窄：`grid-template-columns: 1.3fr .7fr`
- 信号色换掉：`--signal` 可换 `#0047FF`（理性蓝）或 `#00A86B`（资金绿）
- 想更"报纸"：标题字体换衬线（`Georgia` / `Newsreader`），字号 `clamp()` 上限提到 72px
- 网格底纹强度：`opacity` 在 `.08–.20` 之间调

## 反面清单（不要做）

- 不要加圆角
- 不要给信号橙找第二个伙伴色
- 不要把网格底纹加到白底栏
- 不要在深色栏里放表单（那里是叙事，不是操作）

参见 `tokens/colors_and_type.css`。
