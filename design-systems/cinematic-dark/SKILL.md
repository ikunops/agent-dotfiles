# Cinematic Dark

一间暗下来的舞台，一束温暖的光打在标题上。这不是"暗色模式"，是**打光**。

## 风格特征

| 维度 | 取值 |
|---|---|
| 舞台底 | `#0A0A0B` 近黑（**不是** `#0D1117` 那种均匀深蓝） |
| 单光源 | 琥珀 `#E9A23B`，偏心左上（26% 38%） |
| 文字 | 暖白 `#F2F0ED`（不是纯白）/ 次级 `#9A9AA0` |
| 字体 | 标题 Archivo **900**（`clamp(44px,5.6vw,86px)`）；正文 Schibsted Grotesk |
| 分割 | `rgba(242,240,237,.12)` 发丝线 |
| 圆角 | 6px（小，克制） |
| 分栏 | 明显不对称 `1.35fr 1fr` |

## 关键决策与理由

### 为什么是暖色，不是冷蓝？

**这是风格定义的核心，也是最容易做错的地方。** 冷蓝霓虹 = AI slop；暖琥珀 = **有作者意图的打光**。

进一步：琥珀在语境里读作**警示灯**（如果产品是 on-call / 监控 / 告警类）—— 这是内容驱动的选择，不是审美偏好。

判别标准：如果换成任何其他产品，光源色是否还成立？如果是，那它只是装饰。

### 两层伪元素，缺一不可

`````css
.stage::before {   /* 光源 */
  background: radial-gradient(60% 55% at 26% 38%,
              rgba(233,162,59,.20) 0%, rgba(233,162,59,.05) 38%, transparent 68%);
}
.stage::after {    /* 暗角：把视线压回中间 */
  background: radial-gradient(140% 120% at 50% 50%, transparent 55%, rgba(0,0,0,.55) 100%);
}
```

只有光源没有暗角 → 发灰；只有暗角没有光源 → 死黑。

### 入场是一次编排，不是一堆微交互

`````css
@keyframes rise { from { opacity: 0; transform: translateY(14px); } to { opacity: 1; transform: none; } }
.d1 { animation-delay: .05s; } .d2 { .16s } .d3 { .27s } .d4 { .38s } .d5 { .49s }
```

**一次 well-orchestrated 的入场**（元素依次升起，总时长 <1s）胜过十个散落的 hover 效果。这是"电影感"的真正来源——节奏，不是特效。

`prefers-reduced-motion` 时必须全部关闭。

## 核心陷阱（实测）

### ch 单位在中文下会让标题逐字竖排

`.hero{max-width:16ch}` 看着人畜无害，实则是本风格的定时炸弹：

- `ch` = 数字「0」的宽度（本页 15px 正文下 ≈9.2px），16ch ≈ **147px**；
- 英文单词不能逐字断行 → "Incidents" 整体溢出，视觉上 3 行没问题；
- **一个汉字 ≈ 2ch（全角）**，可以逐字断行 → 147px 每行只塞得下 1.8 个字，80px 标题**竖成一条**。

实测数据（1440×900）：英文 3 行 [395/212/210px]，机器翻译后 6 行 [79/79/79/79/79/158px] —— 直接变竖排。

**修法**（已内置在 `preview.html`，翻译态才生效，英文零改动）：

```css
/* Chrome/Edge 翻译时会往 <html> 加 .translated-ltr / .translated-rtl */
html.translated-ltr .hero{max-width:none}     /* 松开父级 ch 限制 */
html.translated-ltr h1{max-width:4.5em}       /* 用 em 限宽：随自身字号，与语言无关 */
html.translated-ltr .sub{max-width:24em}
```

验证：英文版截图像素级零差异（diff bbox = None），中文从 6 行竖排 → 2 行正常。

**新写任何带大标题的页面时**：标题限宽用 `em`（随字号缩放），不要用 `ch`（随拉丁字符宽度，对 CJK 失真）。`ch` 只适合给纯拉丁正文估行宽。

## 微调旋钮

- 想更冷：光源换 `#4A90E2`，但会失去"警示灯"语义，只在纯品牌场景用
- 想更戏剧：光源 `opacity` 提到 `.28`，暗角提到 `.70`
- 想更克制：去掉标题的 900 字重，降为 700
- 入场节奏：总时长控制在 `.6–1.0s`，超过 1.2s 会显得卡

## 反面清单（不要做）

- **不要用均匀深蓝底 + 青紫霓虹 glow** —— 这就是它要对抗的 slop
- 不要在暗场上用纯白文字（刺眼，且失去暖调）
- 不要加多处发光点 —— "单一光源"是全部力量的来源
- 不要每个元素都加动画 —— 编排的意思是"有先后"

参见 `tokens/colors_and_type.css`。
