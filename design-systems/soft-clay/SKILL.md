# Soft Clay

新拟态（Neumorphism）：底色即材质色，凸起与内凹靠**相反方向的双重阴影**区分，加一点暖橘作为唯一彩色。

## 风格特征

| 维度 | 取值 |
|---|---|
| 材质色 | `#ECEEF4`（底色 / 凸起 / 内凹**三者同色**） |
| 暗侧阴影 | `#C8CCD8` |
| 亮侧高光 | `#FFFFFF` |
| 文字 | `#2C3142` / 次级 `#828A9E` |
| 点色 | 暖橘 `#FF7A59` → `#EF5F3C`（渐变） |
| 圆角 | 大而软：卡片 32px，内部元件 16px |
| 字体 | Nunito（圆润无衬线，与材质呼应） |

## 关键决策与理由

- **同色是必须的**：新拟态的力量来自"一块连续材质被推起/压凹"，不是"灰底上的白卡片"。底色一定不能与元件色不同。
- **只有两种形态**：`raised`（凸起）和 `inset`（内凹）。这是材质语法，别发明第三种。
- **动效只用位移**：`translateY(2px)` + 阴影收拢 = 物理按压。不要用 scale/rotate，会破坏"实体"错觉。
- **对比度是天生短板**：新拟态的低对比是它的美学，也是它的可达性风险。正文/标签必须实测 ≥4.5:1；`--ink` 与 `--ink-muted` 的取值已按此校准，不要调浅。

## 桌面布局：两端锚定

新拟态天生适合"居中单卡"，但**桌面端居中会显得幼稚且浪费空间**。正确做法是把它扩展成**一块连续材质板**：

- 左舱：`inset` 内凹凹槽（材质被压进去）
- 右舱：正常平面，承载表单
- 两侧**共属同一块材质**（底色相同，靠阴影方向分舱）

```
┌──────────────────┬──────────────────┐
│  [品牌]          │                  │
│                  │   [表单]          │
│  [大标题]         │                  │
│  [副标题]         │   ← 右舱：平面    │
│   ↑ 内凹凹槽      │                  │
└──────────────────┴──────────────────┘
```

**构图规则**：左舱用 `justify-content:space-between` 做**两端锚定**——品牌锚顶、主张锚底，中间那片空是凹槽的光影（内容），不是死白。

## 核心陷阱（实测）

**移动端的 `display:contents` 会在桌面断点继续生效。**
如果卡片子元素在移动端设了 `display:contents`（为了摊平布局），到桌面断点必须**显式改回 `display:block`**，否则该元素的 flex 子项不被父 flex 接管，标题会浮在中间而不是锚到底部。

实测症状：`.copy` 底边距 760px（等于整个舱高，说明它没被 flex 定位）；`display:block` 后变 60px，与设计意图一致。

## 微调旋钮

- 想更冷：材质色 → `#EBEDF2`，点色 → `#5B8DEF`（蓝）
- 想更软：阴影模糊半径 ×1.3，颜色不变
- 想更实：`--shadow-inset` 的偏移减半，得到更浅的凹感
- 点色面积要**极省**：只用在 logo、主按钮、focus ring。用了第三处就变花。

## 反面清单（不要做）

- 不要用纯白或纯黑做底 —— 新拟态必须"有色材质"
- 不要在暗色模式里直接反色 —— 新拟态的暗色版需要重新调阴影，不是简单 swap
- 不要加装饰几何块填空白 —— 留白用构图解决（两端锚定），不是靠元素填满
- 不要把三种以上阴影方向混用
